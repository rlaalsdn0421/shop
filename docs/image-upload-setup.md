# 상품 사진 업로드 (Vercel Blob)

관리자가 상품 사진을 **내 컴퓨터의 파일로 올린다.** 예전의 "사진 주소 입력"은 없앴다. 이미 주소로 등록된 상품 사진은 그대로 보인다.

## 구조

```
관리자 브라우저 ──(1) 로그인 토큰 + 파일 종류·크기 확인 요청──▶ Next.js 서버 라우트 /api/blob/upload
        │                                                          │ 백엔드(/api/admin/**)에 토큰 확인
        │◀───────────(2) 1분짜리 업로드 토큰 (이미지 3종, 5MB, 랜덤 이름)──┘
        │
        └──(3) 파일 본문을 Vercel Blob에 직접 업로드 ──▶ https://….public.blob.vercel-storage.com/products/….jpg
                                                              │
상품 등록·수정 요청에는 그 https 주소만 실려 간다 ──▶ 백엔드 `product_images.url` (변경 없음)
```

- 파일 본문은 우리 서버를 지나지 않는다(Vercel 함수 본문 4.5MB 제한을 받지 않고, Cloud Run 대역폭도 쓰지 않는다).
- 백엔드는 지금까지처럼 `http(s)://` 주소만 저장한다. DB·서버 변경 없음.
- 서버 라우트는 `ADMIN`/`SELLER`만 토큰을 받게 한다. 백엔드의 `GET /api/admin/orders?size=1`이 200이면 허용(백엔드가 JWT 비밀을 갖고 있어서 거기에 물어본다).
- 허용: JPG·PNG·WEBP, 5MB 이하(Blob이 토큰에 건 조건으로 강제). 저장 이름은 `products/<UUID>.<확장자>`이고 원래 파일 이름은 쓰지 않는다.

## 사용자가 직접 하는 설정 (최초 1회)

1. Vercel 대시보드 → 프로젝트 `shop` → **Storage** → **Create Database** → **Blob** → 이름 아무거나, 접근 **Public**으로 생성.
2. 만들 때 프로젝트 연결을 켜면 `BLOB_READ_WRITE_TOKEN`이 환경변수로 **자동** 들어간다. (직접 값을 복사·붙여넣을 필요 없음. 이 값은 비밀이라 채팅·문서·깃에 붙이지 않는다.)
3. 프로젝트 → Settings → Environment Variables에서 `BLOB_READ_WRITE_TOKEN`이 Production에 있는지 확인하고, 이 변경이 들어간 배포를 한 번 다시 올린다.

설정 전에는 업로드가 503("이미지 저장소가 설정되지 않았어요.")으로 실패하고, 화면에는 "사진을 올리지 못했어요" 안내가 뜬다.

## 로컬에서 쓰려면

`vercel env pull .env.local`로 토큰을 받으면 된다(`.env*`는 깃에 올리지 않는다). 토큰 없이 개발하면 화면의 나머지 기능은 그대로 동작하고 업로드만 실패한다.

## 알아 둘 것

- **올리기만 하고 저장하지 않은 사진**, **다른 사진으로 바꾸기 전의 사진**, **상품에서 뺀 사진**은 Blob에 남는다(지우는 기능 없음, 올라간 사진은 공개 주소로 계속 열린다). 무료 한도(저장 1GB)에서 당분간 문제 없지만, 늘면 `products/` 안에서 어느 상품도 쓰지 않는 파일을 주기적으로 지우는 정리 작업(또는 교체·삭제 시 서버 라우트에서 `del()`)이 필요하다. 아직 하지 않은 일이다.
- 업로드 토큰은 1분짜리다. 로그인이 만료됐으면 사진 선택 시 "로그인이 만료됐을 수 있어요" 안내가 뜬다(작성 중인 폼은 지우지 않는다).
- 파일 형식은 브라우저가 알려 준 종류(`Content-Type`)를 Blob이 확인한다. 파일 내용(매직 바이트)까지 서버가 보지는 않는다. 업로드는 관리자만 할 수 있고, 사진은 별도 도메인(blob 도메인)에서 서빙되어 우리 사이트의 쿠키·토큰에 닿지 않는다.
- 인증 없이 `/api/blob/upload`를 부르면 백엔드 확인 전에 401로 끝난다(토큰이 아예 없을 때). 토큰이 있으면 백엔드를 한 번 부른다.
